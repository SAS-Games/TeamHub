# Milestones.xlsx

Create a separate Excel workbook at the path configured by `MilestoneConfiguration:ExcelPath`.

Use the first worksheet and add these columns in the first row:

| Sl. No | Program | Title | Developer | Milestone | Description | Delivery Date | MS Approval Date | Release Date |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 1 | Program A | Feature title | Developer A | Alpha review | Initial review | 2026-10-15 | 2026-10-20 | 2026-10-25 |
| 2 | Program A | Feature title | Developer A | Beta release | Beta delivery | 2026-11-20 |  |  |
| 3 | Program B | Feature title | Developer B | Production complete | Final delivery | 2026-12-05 | 2026-12-10 | 2026-12-15 |

The three date columns should use real Excel date values. Approval and release dates may be blank. The tracker displays all rows sorted by delivery date.
